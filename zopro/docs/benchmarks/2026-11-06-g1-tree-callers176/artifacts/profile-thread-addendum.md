# Profile worker attribution

The new harness has a main thread, a blocked broadcast coordinator and explicitly pinned Rayon workers. Fixed-period sampling may observe an owned nonworker thread near the measured-region boundaries. Before capture, declare that every sample PID must match the caller, every TID must appear in that process's saved FORK metadata, and every known worker must match its assigned CPU. Owned main/coordinator samples are classified separately and checked against the process affinity mask. At least95%of samples must belong to the declared workerTIDs, in addition to1000samples/unknown<=5%/zeroLOST/exact16Mperiod/mapping/ownership checks. No unknown thread is silently counted as a worker. This is a prospective new-harness eligibility rule, not a post-capture relaxation.
