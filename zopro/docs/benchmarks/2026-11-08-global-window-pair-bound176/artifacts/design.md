# Global partial-window reuse opportunity

Prior bounded SRE screen searched adjacent columns with eight candidates per
bucket. It does not bound global, nonadjacent searches. New fixed screen uses
all 231 pairs of the accepted 22 signed GLV component/window positions.
Reference motivation: https://arxiv.org/abs/2610.27452 (SRE). This is a distinct
necessary work screen, not reproduction of its runtime or a novelty claim.

First separate exact full-scalar duplicates using existing canonical scalars.
Count their ideal nonzero-arrival reduction and charge one point formation
per removed member. Do NOT claim this replays production grouping admission;
that policy and prior failed global/local grouping implementations stay closed.
Then search unique exact-scalar classes, ignoring pairs with a zero digit and
canonicalizing a simultaneous sign. No candidate-count cap, adjacency limit,
window-width sweep or post-result parameter choice.

For each two-column signed class of m members, charge m-1 optimistic tickets.
Sum over all column pairs. A one-generation group sharing k nonzero columns
can save at most (m-1)(k-1) arrivals after formation; it has (m-1)C(k,2)
tickets and C(k,2)>=k-1. For disjoint point groups these forest edges cannot
exceed m-1 per signed pair class. This bounds this fixed pipeline's single
generation. It does not bound recursive created-point reuse, recoding, an
arbitrary MSM algorithm, or runtime speedup. Existing bucket first insertions,
point-part migrations, tree/inversion geometry and cancellation are not priced.

Also execute ONE fixed greedy construction: lexicographic column pairs, signed
classes in sorted order, pair consecutive unused row indices, consume every
same-sign common column, and never use a point twice. Charge each formation.
Two deterministic independent Fr token dot products check residual+new-sum
linear conservation; no elliptic curve arithmetic is executed. This is not
an independent cryptographic verifier. Raw2x2 is not admitted grouped runtime.

all signed two-point gains, and every disjoint two-edge matching optimum must

No old scalar model, suite, native timing/profile or proof is replayed.
