# Native implementation details frozen before first compile

Use the published native-design.md algorithm and padding policy unchanged. Add only a private g2_phi child plus guarded dispatch; all field code and existing streaming kernel bodies stay byte-exact.

Safe descriptor storage holds an empty Vec with a static-reference element type between layers. Consume each borrowed vector through an unreachable map followed by take(0) into a new lifetime; Rust validates that no old reference is transferred. Current Rust1.98.1 preserves its pointer/capacity in20 standalone cases (already executed once, not replayed). The native qualification must check this for actual G2 descriptors. This relies on an optimization for allocation reuse, not for memory safety; another standard library can allocate without changing semantics. No new unsafe code.

Memory: one query-level Reservation::analysis guard lives across the complete hb_raw call. Keep the old forecast unchanged as a floor. Additional checked n-based requested-capacity bound covers all20 ordinary window/part route parents, their two u32 orders, count/start/cursor Vecs, affine outputs, and at most current_num_threads nonforking leaf states. Each leaf charges two compact point Vecs, borrowed descriptor Vec, existing workspace_batch G2 bound, fixed roots/count/offset metadata and struct headers. Use worst-case per-part input skew, including256 possible high roots in the low stage, both retained capacities, and7 padding slots. Bounds use checked add/mul and no fixture-specific distribution. Profile computation does not read witnesses. Disabled/unsupported/ineligible/no-headroom returns before new workspace allocation; admission failure runs the original hb_raw path. There are no new pools or memory-limit flags.

Leaf processing performs no Rayon operation while buffers or scratch are live. Parent metadata uses heap Vecs, avoiding large arrays on suspended window stacks. The small256-bucket arrays and roots belong only to nonforking leaves. Original complete curve operations handle exceptional pairs before generic vector batching. State is reused through for_each_init inside each window; descriptor and compact capacities are retained. Pads copy the first eligible pair's pre-update left value into dedicated appended output slots and borrow the same right/sign, with all inactive outputs truncated before the next level.

Native tests will cover direct tree stages and window routing, all signs/tails, exceptions and cancellation, input immutability and repeated reuse, descriptor storage, bounded profiles/declined dispatch, full MSM reconstruction, and1/4/16/32-worker512KiB-stack pools. No timing inference is drawn from model count reductions. First native compile may reveal ordinary implementation errors; retain failures and fix the failed stage rather than rerunning successful qualifications.
