Compare the complete current G2 borrowed update kernel with a same-input broadcast kernel, using exactly the same admitted updates, signs and bucket addresses. The original has one record per point. The candidate receives one shared point reference and eight signed destinations per packet. Benchmark 1, 8 and 25 packets per batch and 1, 16 and 32 CPU-pinned Rayon workers. Seven randomized blocks per cell, two fresh processes per block, 320 complete updates per worker after four primes. Timing is maximum worker elapsed time divided by update count. Each worker checks every final point against an independent generator-multiple oracle. This component excludes packet formation, lookups, exceptions and task publication costs. Advance to a whole-window prototype if both multiworker widths improve on 8- and 25-packet batches with at least five wins in seven pairs each.
