The sealed design names J(a,b)=(b,-a-b), following an earlier token basis. The implemented model uses J(a,b)=(-b,a-b), consistent with its Eisenstein coefficient basis. Both satisfy J²+J+1=0; the latter is authoritative for this study and its independent reviewer. The original design and all source pins remain unchanged. No arithmetic, result, gate, test or capture is changed or rerun for this wording correction.

The complete hypothetical dense comparator includes the original top position; neither recipe's top is an actual indexed-top execution model.
