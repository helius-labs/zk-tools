# Fixed-size Lehmer inversion experiment

30 October 2026. Production stays accepted source175 / SDK20fde. The preceding vector-sign SDK trial preserves its measured gain and failed calibration; this experiment does not retry or reinterpret it.

Replace only the native fast scalar inverse with variable-time Lehmer extended GCD. A common leading 64-bit projection and Collins stopping condition simulate Euclidean quotients; signed matrix magnitudes are capped at 31 bits before full-width updates. This differs from accepted batched binary GCD, prior low-bit divsteps, zero-run skipping, paired integer SIMD rows and inverse-finish changes. Maintain ordinary extended-Euclid coefficient magnitudes with alternating signs, without modular reduction at each update. One final multiplication restores the Montgomery representation. Exact four-word long division handles a rejected leading-word batch with quotient fitting u64; larger quotients fall back to the original inverse of the original input. Fixed-size arrays only; no runtime heap, table, point copy, new key plan, pool or global memory cap.

The leading-word simulation is adapted from Go math/big's lehmerSimulate (Go Authors, BSD-3-Clause; exact locally installed source and license retained). This is a private prototype, not a constant-time inverse. The accepted inverse is also variable time. Both BN254 prime moduli remain supported; zero returns None. No source or runtime selection change on unsupported platforms.
