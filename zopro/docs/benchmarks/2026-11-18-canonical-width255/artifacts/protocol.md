# Width limit for the canonical CPU solver

The prior broader worker cap aborted in a full-length merge54 process at 96 cores. Its first block improved 1×2 and regressed larger shapes. This revision restricts only the existing canonical-wires CPU path. Its scope returns the witness, gathered scalars, FFT product and correction, drains the parked workers, then starts MSM. The general CPU path uses the original implementation and a route counter. Eligibility follows the existing solver route on the loaded key. Every candidate proof must report exactly one route. At least primary 1×2 must use the canonical route and merge54 must use the general route. All 96-core ON canonical requests must be restricted and every other request unrestricted, with zero timeouts. Consumer-side route counts are checked for every timed process. A scoped worker inside the team or an external caller is supported. This experimental algorithm assumes an exclusively owned executor.

On the local server first verify six fresh process exports on 1×2, 2×2 and merge54 with the same image, public inputs and independent Gnark verifier. Controls use the same executable. Then verify all nine shapes on fresh C7a at 32 and 96 before the main panel. The 234-process remote design uses accepted REF plus same-binary OFF and ON. It retains all eight supplied M5 shapes plus merge54, three full blocks and the paired primary96 observer, stat and sampling panels. Three primes per process. Timed requests per process are one for preflight, 151 for 1×2, 51 for 2×2, 17 for others, and 251 for each primary96 profile process. A complete run means 10,350 timed, 11,052 total calls. Starting ledger 64,564, after six local 64,570, after full cloud 64,804. Each completed remote export must pass the host Gnark verifier after retrieval.

Require 1×2/96 ON faster than OFF and REF in all three blocks, median paired CPU ratios no greater than one, OFF/REF within a factor of 1.03. Check other contexts for median ON/OFF ≤1.03 and maximum ON lifetime RSS ≤1.10×REF+8 MiB. Preserve scoped evidence if a wider criterion fails. Three blocks form a screen. The M5 target is independent of these comparisons. Observer tolerance factor 1.05, ≥1,000 samples per event, ≤5% unresolved, no loss, full counter scheduling and fixed bindings.
