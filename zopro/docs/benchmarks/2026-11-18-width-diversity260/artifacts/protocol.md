# Factorial comparison of phase width and early G2 grouping

Compare both changes on and off independently in the exact 257 binary. On 96 physical cores use four arms: neither, only the 32-worker canonical frontend, only the concurrent G2 diversity check, and both. Also run d523 accepted Zopro, exact 255 with its width limit, and retained Aeglos on the same 96 cores. An eighth arm runs both selectors on 32 cores, where the width limit is inactive. Use the same 1×2 image/request, exact single-proof SDK, fixed core affinities and verified serialized outputs. No recompilation of any measured engine. Check exact binary identities, route and certificate counters for every timed call, and host/remote Gnark on every export. The reference controls have no profiler.

Eight preflight processes make three primes and one timed request each. Seven rotated/reversed blocks use independent byte-identical executable backings, eight fresh processes per block, three primes and 151 timed requests each. Finish every plain block before final verification. Total 64 exports, 8,464 timed calls, 8,656 calls including primes. Seed 65,069 to 65,133. Each aggregate is the median of seven process means. For each block calculate both single-factor ratios conditional on the other factor and the multiplicative interaction (both × neither)/(width × cert); report all seven, median and wins. Conditional effects are measured on this one workload and host. Also compare 32/96 both and the same-host Aeglos baseline. Require OFF/accepted and width-only/255 control calibration within a factor of 1.03 for direct attribution versus retained binaries, separately from same-binary attribution. This is a follow-up for 1×2. The all-eight objective remains unchanged.
