Serial CPU scopes are restricted to the primary path's synchronous fill_window_deferred, fused K/H feed, ordinary (non-top) G2 hb_window, stream_g1_impl, g2_prefix::apply, reduce_layer, invert_lanes and direct_chain_inverse. Weighted/group/index tiles and merge chunks have their own explicitly parented serial scopes inside Rayon callbacks. Their bodies invoke sequential field/curve operations and sequential batch_to_affine; the parallel launchers themselves are wall-only scopes. The top-window branch returns before the ordinary G2 serial scope.

CLOCK_THREAD_CPUTIME_ID measures user and kernel CPU charged to that OS thread, including observer overhead. Exclusive recorded serial CPU subtracts the nearest serial descendants and checks same-thread CPU containment. Window/root callbacks remain wall-only because they can execute other jobs while joining. Parent IDs are captured as integers across every instrumented nested parallel closure; whole query entry resets the explicit request parent so grouping cannot inherit a waiting sibling window.

Kernel-input availability is measured at A/KH kernel entry and after G2's scalar-decomposition barrier. These are not queue-enqueue timestamps. Unrecorded preprocessing, point scattering, folding and unrelated SDK work remain uncovered; no inference of a complete removable critical path follows. A/B/metadata/field writes and scheduling decisions remain exactly those of the accepted source after stripping the recorded insertions/wrappers.
