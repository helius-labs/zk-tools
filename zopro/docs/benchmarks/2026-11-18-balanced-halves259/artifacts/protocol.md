# Balance two G2 partitions by sampled digit length

Use the same two contiguous parts, window width, arithmetic, grouping and point order within each part. After the in-place endomorphism split, divide the input into 256 equal-length strata, estimate work at the center of each by signed component magnitude lengths and the identity flag, and interpolate a cut at half the estimated work. Weights include a fixed visit cost and the number of 12-bit positions in each nonzero magnitude. This is an approximate work estimate. Every row belongs to exactly one part. The sampler uses 256 machine words of stack and releases them before the fills. No extra bucket arrays or per-point indices.

Test complete signed, zero, identity and fixture queries with independent point outputs, odd lengths, and equal-work fixtures. Then use the local 1×2 and grouped 2×2 query fixtures at 16/32 workers, OFF/ON, three process backings. Each process runs 3 primes, 17 timed queries, and one postcheck. Retain wall, CPU and peak RSS. A directional component result means a lower paired median against OFF; preserve mixed cases. Full SDK latency and 96-core timing require separate checks. The experiment does not choose an input-specific fixed boundary.
