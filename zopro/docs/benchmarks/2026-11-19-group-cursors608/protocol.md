# Stable class lists with a single offset array

When scalar grouping succeeds, Zopro copies the class starts to an equally sized temporary insertion-cursor array. The alternative uses slot g+1 of the final offsets to write members of class g in original order. After all members arrive that slot equals the class end. The existing counts, class numbers and order by first occurrence are preserved. On a 64-bit machine this eliminates one eight-byte temporary element per distinct class. The existing optional memory forecast is retained.

Seven shuffled local blocks compare the prior executable, the same-source control and the alternative on five public transfer requests with all 32 logical workers. The 1×2, 2×2 and 4×2 shapes use their previously selected centered key profiles, including sampled H on 2×2 and prepared groups on 4×2. The 5×16 and 6×2 crossover requests use the ordinary catalog keys and environment. Each process primes three requests and times 31 complete verified calls on 1×2 and 2×2 or 15 elsewhere. Separate probes count classes entering the new scatter. The raw count summed across groupings measures allocation volume eliminated per proof, not simultaneous live memory. An independent oracle checks the stable class lists and weighted curve sums in the native grouping tests.
