# Fused G2 product components minus canonical anchors

For each real/imaginary component, preserve the accepted mixed R256 fused CIOS recurrence, including the accepted representation of negative factors as2p-c. Let X be its nonnegative integer two-product sum. Inputs at most2p give X<=8p²; R=2^256>4p. Canonical Montgomery quotient q=-X/p modR gives T=(X+qp)/R<p+8p²/R<3p. The original fused primitive normalizes T and conditionally subtracts2p, then a separate field subtraction removes a canonical host anchor a<p.

Instead, after the original mixed48bit repacking but BEFORE final normalization, normalize signed coefficients t[j]+p[j]-a[j]. This represents U=T+p-a with0<U<4p (allowing inclusive a=p gives0<=U<4p). Exactly one conditional subtraction of2p returns a normalized representative below2p, congruent to T-a modulo p. The output need not have the same lazy representative as the original separate sequence; canonical field values agree. Every downstream consumer must retain the established normalized <2p contract.

All original product/cancellation coefficients remain conservatively below2^61. Adding a modulus digit and subtracting a canonical digit plus signed carry remains well inside signed64. Arithmetic shifts produce exact radix52 signed carries; the final total U is nonnegative and below4p<R, so the terminal carry is zero. Fused correction uses the original reduce_fused/conditional subtraction without changing its bound or lookup policy. No inverse constants, buffers, tables or copied keys are added.

Private API preconditions: eight native lanes, Fq/Fr modulus<2^254, MIXED=true, fused=true, normalized multiplicands<=2p, anchor canonical<p. Only Fq/R256 G2 expression calls are timed. Uniform and four-lane dispatch are not proposed. The additive helper is included only in a private copy, not production. Original ordinary/fused APIs remain exact.
