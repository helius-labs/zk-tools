# Current subgroup control backing diagnostic

The old OFF inode remains about **14.3% slower** than REF, but a byte-identical OFF copy matches a REF copy: paired OFF/REF **1.00012**, 95% interval **0.99856–1.00176**. Every profile has the same executable virtual address. This supports executable backing as a factor in the current control discrepancy; it is not an arithmetic optimization or proof-speed result.

An [earlier G2 MSM study](../2026-10-28-g2-control-copies/README.md) already observed this class of backing-associated effect. This experiment confirms it for the current subgroup-call binaries, following the [current ELF/address-layout audit](../2026-11-10-branch-control-audit176/README.md). It does not newly establish a general mechanism, overturn earlier failed candidates, or resolve every historical calibration failure.

The slow backing does not show a simple increase in these aggregate op-cache miss, line-fill or ITLB counts. Event units are different: accesses, 64-byte lines and fetch translations are not additive stall cycles or exclusive wall-time fractions. Fetch-service latency, physical mappings and specific branches were not isolated. The existing [whole-SDK dispatch study](../2026-10-26-front-end-counters/README.md), [streaming operation/fetch IBS](../2026-10-29-stream-ibs175/README.md) and rejected [fused-field outlining](../2026-10-29-g2-fused-outline175/README.md) remain relevant prior evidence; this narrow harness does not justify repeating them or predicting a twofold proof gain.
