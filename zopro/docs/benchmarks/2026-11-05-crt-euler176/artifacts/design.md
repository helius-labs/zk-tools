# Auxiliary-prime Euler derivative: exact algebra stage

The accepted Euler product computes n*(E(A)*B+A*E(B)) on the n-th-root domain, where E(f)=X*f'. It currently performs an inverse and forward Fr transform for each of A and B. We will test a different whole-operator representation, not another per-field RNS multiplier.

For omega of exact order n, E evaluated on that domain is cyclic convolution with K[0]=(n-1)/2 and K[j]=1/(omega^j-1), j nonzero. Derive this by differentiating the Lagrange cardinal polynomials. Let rho have order 2n. Multiplying both input and kernel coefficient j by rho^(-j) converts this cyclic convolution to a negacyclic one over Fr; multiplying output coefficient j by rho^j restores it. The identity rho^n=-1 changes the negacyclic wrap sign back to a positive cyclic wrap. Include the accepted unnormalized factor n at output.

Lift the twisted canonical Fr inputs/kernel to nonnegative integers. Each integer negacyclic coefficient has absolute value at most n*(r-1)^2. Distinct auxiliary primes with product Q>2*n*(r-1)^2 permit exact signed CRT reconstruction before reducing modulo Fr. It is incorrect merely to reduce Fr values into small primes and assume their roots represent the Fr transform. Twisting occurs in Fr, not independently under each auxiliary prime.
