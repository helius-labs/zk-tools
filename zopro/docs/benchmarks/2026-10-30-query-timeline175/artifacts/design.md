The balanced G2 full SDK trial reduced primary CPU service by about 6.36% against accepted but yielded only a 0.416% paired primary wall gain. Its whole performance gate failed. The former stage-uprobe diagnostic also failed parallel probe-overhead qualification, so its near-simultaneous G1/G2 return observations are not an unperturbed critical-path measurement.

This study adds low-frequency in-process timestamps to the exact accepted primary fused branch. It does not integrate the failed balanced G2 candidate. Rayon join nesting and all arithmetic calls remain unchanged. A starts after product completion exactly as before; no new scheduling or overlap is introduced.

One fixed-capacity journal holds at most 256 records of thirteen u64 nanosecond offsets (26,624 bytes requested), allocated before primes in both disabled/traced processes. A Start carries an optional monotonic Instant by value across query closures; no locks occur at query boundaries. A single mutex push occurs after output serialization at the joined proof boundary. Records contain no point, scalar or proof values. Overflow rejects analysis; it never silently truncates or grows the journal during measurement. This is diagnostic memory, not production admission or a minimum-RAM claim.

The modified SDK consumer uses its original timing/verification/export loop, prepares the journal before primes, enables it only after primes, and drains/serializes it after timing. No portable/performance/adoption claim follows from native tests.
