# Five-point rational-intersection work screen

Hypothesis: a rational cubic/linear curve through five arbitrary affine inputs can recover their sum using one final batched inversion rather than three binary reduction levels. Derive and check a fixed division-free construction before considering native code. This is a new local derivation, not a claimed literature novelty or a performance result.

For five finite distinct-x inputs (xi,yi), define dij=xi-xj for i<j, Delta=product(dij), V=product(x-xi). Let Ni be the product of the six dij edges not incident to i, and Wi=(-1)^i yi Ni. Set Y=sum Wi*V/(x-xi), so Y(xi)=Delta*yi without division. If v4 is V's x4 coefficient, u=Y4 and v=Y3-u*v4, then N=(ux-v)Y-u²V has degree at most3. The rational function N/[Delta*(ux-v)] interpolates the inputs whenever the denominator is nonzero there.

Write N=n3*x³+n2*x²+n1*x+n0 and D=d1*x+d0=Delta*(ux-v). The polynomial N²-D²*(x³+b) has the five input x-roots plus x6. Set Z=n3, Z2=Z² and X=d1²-2*n3*n2+v4*Z2. Then x6=X/Z2. Put H=d1*X+d0*Z2, Nh=n3*X³+n2*X²*Z2+n1*X*Z2²+n0*Z2³ and I=1/(Z2*H). The sum is (X*H*I, -Nh*H*I²). Exceptional distinctness/interpolant/normalization conditions must decline transactionally; independent complete group addition remains the oracle.

Use a fixed shared-product network for Ni and Delta, not ten independent field inversions or an unbounded matrix solver. Count every field product and square, normalization/inversion, and intermediate degree. Check interpolation and factorization identities as well as the final group sum for G1 and G2. Use fresh public deterministic full-width scalars, plus identity/equal-x/opposite/identity-sum degeneracies. No prior successful native/model/proof test is replayed.
