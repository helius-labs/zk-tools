solver screen with a full SDK screen. Public accepted APIs expose complete proof
parts, not a raw Plan caller. Adding a new diagnostic Plan wrapper would change
the source currently being qualified. Reuse the established SDK driver and
accepted frozen SDK control instead. This measures the requested outcome
directly. No candidate timing influenced this decision.

from each process and verify independently with Gnark. Each output public-witness
hash must match the retained fixture. Automatic PMUs and cycle profiles follow
all latency, with251 requests. No other owned workload overlaps captures.

based on outcomes. Calibration and nonregression bounds use the inherited1.03
