New converter: exact mixed-radix digits via triangular inverse operations, then Horner evaluation in each of the five destination moduli. It removes CRT weights and quotient estimates but introduces four sequential digit rounds and four Horner rounds per conversion. There are two conversions per Montgomery reduction. No hard latency prediction from these levels.

Check M>64p,N>8p and therefore 0<=Z<3p<4p for both BN254 fields. Both bases must reconstruct the same integer and agree with independent BigInt Montgomery arithmetic. No production binary converter or curve implementation is implied.
