# Restoring arbitrary-parts calls on preconverted Euler keys

The diagnostic preconverted image originally supported only full solves. For independently supplied parts, the amended path projects the original private K scalars through the A and B row forms. Public wire values and retained prefix-slot scalars are zero in that projection. Other slots are reconstructed from their defining linear expressions. The path subtracts the two public-origin cross terms from the existing K correction, leaving the arbitrary A/B/C quotient and the public proof format intact. The temporary projection lives only for a generic parts call. The complete-proof hot path retains the existing transformed queries.

An attempted replacement of the solver on a mapped-origin key now compares the full canonical solver serialization against the original plan using streaming SHA-256. The native and portable tests check that changing a B-query index changes that digest even when the C digest is the same. They also compare projected row commitments against an independent reverse fold on fresh and reloaded plans for empty, alternating and complete retention of the extra slots.

Four independent inputs per key exercise zero, sparse, dense partial-domain and dense full-domain arbitrary values, including C supplied independently of A and B. All five returned component encodings matched the ordinary image byte for byte for both 12×2 and merge-24×1. Sixteen additional complete SDK exports on the original and three held-out transactions per shape passed the ordinary verifier. This is a compatibility test; the complete-proof samples are one process per arm.
