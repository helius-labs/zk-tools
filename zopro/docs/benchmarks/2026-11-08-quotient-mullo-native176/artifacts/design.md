# Low-word multiplication for CIOS quotients

Selected before native implementation/qualification/timing. Each eight-lane CIOS product has five quotient steps m=(t0*INV) mod2^k, with k52 in ordinary rows and k48 in the mixed final row. Replace only their zero-accumulator IFMA low product with VPMULLQ, under private compile selector zopro_quotient_mullo. The mask, cancellation, all data/modulus products, mixed packing, normalization and lazy ranges remain byte-exact. No alternate width, unrolling, layout, correction or instruction-attribute sweep.

For any u64 x,y and k<=52, low_k((x mod2^52)*(y mod2^52))=low_k(x*y mod2^64). Thus the quotient is bit-exact for all inputs, including unnormalized t0. Five IFMAs become five VPMULLQs: nominal ordinary/fused IFMA counts100/150 ->95/145, without reducing total multiply instructions. Existing accepted code already uses VPMULLQ for small R260 import/export factors, but not these CIOS quotients. Bounded history search found no exact previous quotient substitution; no exhaustive novelty claim.
