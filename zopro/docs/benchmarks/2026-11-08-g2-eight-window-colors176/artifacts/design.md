Generic scalar affine exceptions are not modeled; this is not native curve qualification.

Count every active/inactive vector lane, color/root bridge, first assignment, part merge, phi map, original projective overflow and normalization; price vector and scalar operations separately. This is the inherited source census, not a cycle model. New masked fill substitutes vector-row count for floor(n/8) and color count for calls. It adds unpriced mask/select/broadcast/gather/scatter/coloring work. Part merges retain original BatchAdd formula.
