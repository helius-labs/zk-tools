# Dedicated G1 placement beyond the 1×2 circuit

The four shapes compare the retained Rust prover profiles, same-binary placement controls, and prepared Aeglos. Zopro's experimental path moves canonical G1 A to the existing caller-attached frontend pool. The group route retains ordinary grouping and the raw route bypasses it. Separate core masks hold the total at 96 physical cores. Each process primes three requests and times thirteen verified requests. Independent verification passed all 344 exported proofs. The C7a instance and temporary resources were removed.

The table selects the best dedicated configuration by mean relative median across the two inputs. This selection uses four screening blocks. The placement counter is from a separate four-request routing check at 80+16. On the supplied M5 16×2 reference the fastest observed Zopro arm was 64-group, at 31.603 ms, or 10.60× the M5 CPU and 3.92× Metal. It met the 33.5 ms target in 4/4 screening blocks.
