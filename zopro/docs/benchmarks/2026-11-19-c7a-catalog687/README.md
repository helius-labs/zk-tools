# Current Zopro and prepared Aeglos on the full C7a circuit catalog

All 41 pinned keys ran on the same c7a.24xlarge with 96 physical cores and SMT disabled. Each shape used 32 and 96 workers. The eight original M5 reference shapes also compare two indexed Zopro settings, and 12×2 and 24×2 include a 64-core measurement. Each of six blocks runs both engines with the same request and main CPU mask, three warmups and seven timed single proofs. Engine order in a matched group reverses in consecutive blocks. All 1,224 exported proofs passed the host verifier and independent local reverification. Prepared Aeglos reported a cache hit on every timed call. Timing is the median of process means. RSS is the highest process peak including preparation.

At 32 cores the catalog release median was lower on **41/41** shapes and all six paired comparisons favored Zopro on **41/41**. At 96 the counts were **24/41** and **23/41**. The paired counts are descriptive. Across the two tested widths, Zopro's own median improved on **19/41** shapes when moving from 32 to 96.

The three largest 96-core release gaps were 1x16 (20.159 / 12.751 ms), 1x4 (15.426 / 9.852 ms), 1x8 (16.676 / 10.807 ms), in Zopro / Aeglos order. The separate configuration screen uses these measurements to identify shapes that need more work.
