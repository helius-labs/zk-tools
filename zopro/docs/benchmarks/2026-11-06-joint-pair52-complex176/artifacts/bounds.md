# Joint complex signed-coefficient bounds

Let B=2^52, with normalized limbs in[0,B). Each elementary diagonal low/high piece is belowB. For each product and limb pair i<j, use cross=di+dj+(ai-aj)(bj-bi). Orient the first difference nonnegative x and the second to signed y. IFMA sees ymodB, so subtract x from the high coefficient wheny<0. This gives an exact product with low digit[0,B) and corrected high digit strictly between-B andB. A negative cross contribution reverses the original second difference before orientation; the same argument applies without a separate full-product negation.

The real diagonal vectors are DP-DQ, each low/high piece strictly between-B andB. The imaginary diagonal vectors are DP+DU for normal multiplication, or DP-DU for conjugation. The split diagonal polynomial E has endpoints below2B in magnitude and four middle terms below4B; its six-term prefix/tail schedule therefore has absolute value below20B, including intermediate sums. The real signed-difference case has the tighter10B envelope. Every output coefficient receives at most two low and two high pair contributions per raw product. With only two products contributing to each output, the intermediate bound is below20B+8B=28B<32B. The shared P high piece is corrected before it is added to both output coefficients. This bounds arbitrary full-width52-bit limbs, not only field inputs.

For cancellation radix b=2^52 or2^48, q=-t0*p0^-1 modb makes t0+q*p0 divisible byb. Since p0 is odd, (t0+q*p0)/b=ceil(t0/b)+floor(q*p0/b) holds for negative t0 as well: when t0modb is nonzero the two nonzero residues add tob, and when it is zero q=0. Arithmetic shifts compute the ceiling as(t0+b-1)>>log2b. The high52product of(q<<4)*p0 supplies floor(q*p0/2^48) in the last mixed row. Each later coefficient receives at most two modulus-product pieces per cancellation row, and only one carry from its preceding row. The parent32B input argument gives pre-shift coefficients below64B; final multiplication by16 and its carry remain below1026B<2^63. The model checks every actual stored lane but observed maxima do not replace this general argument.

Linear preprocessing maps sums/differences into[0,2p], preserving residues modulo p. All three raw products P,Q,U are in[0,4p²]. R256>4p holds for both primes and also implies3p<2^256. Signed T=P-Q or P-U is in[-4p²,4p²]. The full Montgomery quotient q is chosen in[0,R), so REDC(T)=(T+q*p)/R lies strictly in(-p,2p). Nonnegative T=P+U has REDC(T)<3p. The same bounds hold forR260 with additional headroom;8p<R260 implies its unsigned output<2p.

After four arithmetic radix52 carry steps, the lower four digits are in[0,B) and the top remains signed. The integer is negative exactly when that top is negative. For a signed result, conditionally add the five digits of2p and normalize again: a negative value in(-p,0) becomes a value in(p,2p), while a nonnegative value already lies in[0,2p). For the normal unsigned imaginary result, subtract2p when the value is at least2p; its<3p bound then leaves[0,2p). Final top digits are nonnegative and belowB because2p<2^255<B^5. None of these raw values is constructed as an unreduced host Fp object. The intended native signed-top correction needs different code from the old nonnegative reducer.

The complex algebra is checked modulo p after preprocessing. For the normal product, S=a0+a1,T=b0+b1,D=b1-b0 give P=S*b0,Q=a1*T,U=a0*D and(real,imag)=(P-Q,P+U). For a conjugated second input, T=b0-b1,D=b0+b1 instead give(real,imag)=(P-Q,P-U). Divide both by the same input Montgomery radixR. Normal expected residues are(a0*b0-a1*b1,a0*b1+a1*b0); conjugated residues are(a0*b0+a1*b1,a1*b0-a0*b1).

Diagonal real/imag mixing costs20add/sub operations; two shared diagonal convolutions cost26. For ten cross pairs, the three difference/sign recipes cost21vector/mask operations, and sharing the two P pieces across two outputs costs four additions:250more, total296. Input field sum/difference operations, correction/carry ALU, comparison masks, loads, moves, constants, scheduling, code size and spills are excluded. This is not an optimized instruction count or a native latency bound.

The joint source has twenty live output coefficients during the cross phase. At eight lanes their logical payload is1,280bytes, before inputs, preprocessed sums and difference temporaries; this is not an actual frame or lifetime/peak measurement. Three separately materialized convolutions would add unnecessary live arrays. A native implementation must use the joint dataflow and inspect final compiler scheduling/register allocation. Ordinary field multiplication and FrFFT are not part of this proposed API change. Correctness/model arithmetic cannot establish a proof speedup, memory qualification or safe adoption.
