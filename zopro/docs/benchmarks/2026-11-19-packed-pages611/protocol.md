# Transparent huge-page advice for the packed FFT output

On the local x86-64 Linux host, the PMD huge-page size is 2 MiB. Advise only complete aligned PMD ranges within the uninitialized first-layer output vector via MADV_HUGEPAGE. The original column workers then write into that vector. The kernel decides whether to back pages with huge pages. A failed advice call leaves the numerical path intact. Allocator-owned address ranges can retain the advice when subsequently reused. The global loader configuration is held fixed. The implementation allocates the original output once and adds no lookup table.

Five shuffled blocks on 12×2 and 24×2 each measure the original and one held input. A two-by-two comparison crosses ordinary main-pool versus selected auxiliary-pool computation with advice off versus on. A separate frozen auxiliary arm checks the comparison build. Three warmups and eleven measured full proofs use common main affinity within each block. Separate diagnostics must observe successful advice without crossing allocation boundaries. Native tests compare packed arithmetic across both root layouts and check aligned spans and overflow. Report full latency, minor faults and process peak RSS independently.
