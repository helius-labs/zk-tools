# Zopro, Aeglos, and Gnark on 96-core C7a

All 41 circuit shapes ran on a single c7a.24xlarge. Each comparison used the same request and proving key for all three engines. The single-proof panel measured both the catalog and held-out inputs. The parallel panel used separate warmed prover processes for the catalog request.

Zopro had the lowest peak RSS in 82/82 cold cases and 82/82 hot cases. In the parallel panel, Zopro had the highest throughput at 10/10 settings and the lowest group memory at 10/10.

## Single-proof latency and memory

Cold time starts at the runner’s main entry and ends at its first verified response. It includes key loading, initialization, witness construction, proving, and verification. Each process starts without a prepared prover. Fixture checksum validation reads files before the timed groups, so the host file cache is shared. The independently verified first export binds this timing to a valid proof. The cold RSS is the process high-water mark through that response.

Hot time starts after three prime proofs. Each process measures five warm responses. The hot RSS is the process high-water mark after the warm loop, including startup. Each latency cell is the median across three engine-order-balanced blocks. The leads above compare those displayed medians. Each hot block contributes its arithmetic mean. Each memory cell is the maximum across blocks. The load response excludes queue waiting behind earlier requests in the same worker.

## Builds and verification

Zopro used one AVX-512 SDK build and shape-specific worker settings from the previous scorecard. Aeglos used its CPU backend at revision 0290613 with automatic ISA selection. Gnark used its Groth16 BN254 prover from v0.16.3 with gnark-crypto v0.21.0. The three builds and all input hashes are recorded in the protocol. Every Aeglos first request recorded a preparation-cache miss, and every timed hot request recorded a hit. The 12×2 run uses the standard Euler image after a first instance stopped at the older mapped image. The first instance was removed. The tables use the completed replacement run. These are fresh measurements with the listed builds. Earlier Zopro and Aeglos comparisons used other pinned binaries.
