# Integrated medium K and H bucket sharing

The public native prover can stream K and H into the same buckets when B1 is omitted, H has unit scale and each query has 1,024 through 65,535 points with a combined count of at least 65,536. Setting `ZOPRO_CPU_MEDIUM_KH=1` enables the additional path under the optional workspace allowance. The selected local profile is 2×2 at sixteen main workers with eight frontend workers on one L3. Eight independent witnesses favored sharing by 1.98% median paired against the same disabled executable. At 32 workers four of eight favored it.

The integrated workspace passed 153 native core tests and 106 portable core tests. On the public Cargo executable, the enabled route ran on all four requests in its trace probe. The disabled and zero-budget probes selected the ordinary path. All three exported proofs passed independent Gnark verification. The benchmark also exposes early public verification to reproduce the established 1×2 configuration.

The C7a completion-trace runner passed a separate local smoke test on both requested shapes at 16 and 32 Ryzen workers. Its twelve proof exports were reverified. The corresponding 64/96-core cloud measurement remains outstanding.
