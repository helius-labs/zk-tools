# Bounds and stable grouping review

Equal full-word scalars have the same low three bits, so an exact HashMap can determine equality independently in each of eight shards. Stable counting partition preserves original input order within every shard. Its first representative is therefore the original global first occurrence. Reconstruction traverses original positions; every nonfirst representative points backward to a class ID already installed. The returned values, counts, starts and stable index lists match the original serial representation exactly, including skipped zeros and empty groups.

No output scalar array or point representation is duplicated during partitioning. Each nonzero input has one8byte(original index,representative index) pair. Existing canonical/Montgomery words are read without mutation. Each map uses the original owned32byte key andu32value type; every growth envelope uses the existing checked hash_table helper for that shard's population, including its retired allocation. Summing all eight envelopes conservatively allows their peaks to coincide. The pair buffer, sample-set envelope and fixed descriptors are included. All maps drop before reconstruction begins.

Reconstruction's checked bound includes pairs, original-position class IDs and growing scalar-value/count vectors. Pairs drop before starts/positions/order list construction, whose representation and bound remain original. The unchanged G1/G2 consumer costs remain covered. Both new preparation peaks must fit the existing checked grouping_cost::peak(n,percent) charge before the first pair allocation; otherwise the unconsumed reservation returns to the untouched serial code. Single-worker and small inputs also return before partitioning/allocation. Arithmetic overflows decline the optional path.

The forecast describes requested live allocations and inherited growth assumptions. It is not a universal RSS bound or minimumRAM; allocator retention, worker stacks, concurrent calls and pressure still need actual qualification before adoption. Fixed histogram and segment descriptor space is charged conservatively; no persistent key cache/table or duplicate solver plan is introduced. Tests exercise balanced/adversarial populations and overflow, stable metadata at both cutoffs, nesting/concurrent callers and the unchanged fallback. Whole-SDK memory and timing observations remain necessary and are not replaced by this review.
