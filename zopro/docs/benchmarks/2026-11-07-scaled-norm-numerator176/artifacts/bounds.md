# Raw reduction semantics and matched-scale invariant

Let p be either BN254 prime, H=2^256 and R=2^260=16H. For numerical inputs a,b,c,d in[0,2p], ordinary fused T=ab+cd satisfies0<=T<=8p². The complement difference T=ab+(2p-c)d has the same bound and differs from ab-cd by a multiple of p. Existing uniform-radix REDC chooses0<=k<R so T+kp is divisible byR, returning U=(T+kp)/R. Thus0<=U<p+8p²/R<2p because8p<R. The strict bound includes inclusive2p input endpoints. Existing normalized-digit contracts remain sufficient.

Interpret raw a as the ordinary R256 field value A=a/H modulo p, and similarly B,C,D. Interpret raw output U in R256 as well. Then U/H=(ab+cd)/(RH)=(AB+CD)/16 modulo p. Complement difference gives(AB-CD)/16. This is a deliberately scaled operation on ordinary R256 field values, not an import into an R260 storage domain. The wrapper must access raw limbs and return them under the R256 type without calling R260 new/get. There is no runtime multiplication by inverse16 in the proposed native implementation.

For each full vector group, define n=dx0²+dx1², u=dy*conj(dx), n'=n/16 and u'=u/16. Existing prefix C0=1, C(i+1)=Ci*n'i and reverse inverse sequence give factor Ci/C(i+1)=1/n'i. Hence slope=u'i*factor=u/n. Existing x/y formulas are unchanged. The shared inverse bridge operates on ordinary R256 values C(i), so it automatically includes the accumulated scale16^-i; no group-dependent correction or table is needed.

Scalar tails keep their original unscaled norms and numerators. Their numerators include the current (possibly scaled) lane prefix. Multiplying by the inverse of that prefix times tail norms cancels the prefix as before; reversing those original tail norms restores the full-vector prefix inverse. This also covers zero full groups, all short lengths and incomplete final groups. Different tail counts per lane do not require equal lane roots; the original eight-lane batch inverse already handles distinct roots.

All indices in one streaming batch must remain distinct and incoming points immutable, as required by the accepted kernel. Signs affect dy and leave dx/n unchanged. Multiplication by inverse16 preserves zero/nonzero classification. Equal-X, identity, doubling and cancellation routing stays with the accepted feeder; this finite-point model classifies invalid/incomplete batches before mutation and does not implement production fallback.

The native scope must couple BOTH norm and numerator changes. Replacing only one scales the slope incorrectly. Generic Fq2 inversion helpers and the final-Y complex product remain original; they are not interchangeable users of this scaled primitive. G1, generic trees, scalar tails and point/key encodings do not change.

The exact model checks20,012new REDC outputs across Fq/Fr against separately evaluated Arkworks logical field expressions, including inclusive corners, limb boundaries and changing chains. Its complete point model uses both scale1 andscale1/16 on fresh public fixtures and checks21,717candidate outputs against independent complete Arkworks projective addition. These are finite correctness evidence plus the algebra above, not native execution, a universal formal proof or a timing prediction. The native candidate should reuse the already qualified uniform-R260 kernel, then independently validate its new raw wrapper and coupled G2 callsites.
