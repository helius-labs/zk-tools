# Start G2 weighting when the second bucket range is ready

The release nests a two-part Rayon computation inside each signed window. The trial submits all window/range fills to one parallel iterator. The first task to finish a window’s range publishes its existing bucket vector, then returns. The second task takes that vector and runs the unchanged merge and weighted reduction immediately. Locks protect only the handoff. No worker holds a lock while computing curve operations. The original range order is restored before merging. The added proof-local metadata has one slot per window. Peak RSS is measured independently. The two schedules enumerate neighbors by window or by range.
