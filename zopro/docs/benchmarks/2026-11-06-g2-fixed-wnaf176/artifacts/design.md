# Fixed-block odd-digit recoding: algebra before cost selection

Read the primary implementation at https://github.com/bitcoin-core/secp256k1/blob/master/src/ecmult_impl.h, functions secp256k1_wnaf_fixed and secp256k1_ecmult_pippenger_wnaf. This is conventional fixed-block odd recoding with a scalar skew correction, not a new algorithm. The earlier g2-wnaf-screen176 only tested bitwise NAF with127positions. It explicitly did not test this construction. No secp256k1 curve/speed claim transfers automatically to BN254.

Independent Rust arithmetic below uses the inherited G2 component bound <2^126, width12, eleven fixed radix4096positions. Nonzero digits are odd with absolute value<4096; zero scalar maps to allzero with noskew. Even nonzero magnitudes use a unit skew; a local adjacent-digit rewrite may remove some coefficients. Reconstruction is sum(digit[w]*4096^w)-skew. Component sign applies to both digit terms and the correction.

No native route, proposed runtime digit table, key/precomputation change or speedup is established. The FIRST cost question is all eleven positions plus the mandatory correction, occupied bucket first writes, part merges, odd-weight reduction/doublings and the original special indexed-top comparator. Do not repeat the bitwise screen's initial ordinary-only comparator mistake. Use source-extracted original Phi2 and pinned actual primary and grouped2x2 data only if algebra succeeds. Test whole component identities first; scalar algebra alone does not qualify curve routing, memory or timing.

Important limitation visible before counts: width12 fixed odd digits need2048positive magnitude buckets, the same capacity as balanced radix12, with a correction added. Do not claim halved buckets or savings from oddness alone. Bitwise NAF's smaller magnitudes used a different number of positions. Any opportunity must come from actual zero/carry populations or a separately justified complete reduction, not from mixing the best aspects of incompatible encodings. No width/lattice/skew-elimination parameter sweep is selected here.
