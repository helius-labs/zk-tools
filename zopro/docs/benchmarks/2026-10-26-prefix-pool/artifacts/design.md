# Preparation before full-pool entry

The prior goal turn only reported status: no new progress. Production remains the accepted 170-source manifest. This private experiment tests a distinct critical-path change motivated by the existing C7a phase measurements: solver wall time rose from 2.24 to 2.92ms and FFT from 0.91 to 1.38ms between 32 and 96 workers. Those observations do not establish a cause or predict a speedup.

For the existing native Linux IFMA canonical/fused-KH small-proof eligibility, an explicitly enabled shared eight-worker process pool performs solver, public correction, canonical conversion, gathers and product FFT before the caller enters the global arithmetic pool. Arithmetic kernels and A/KH/G2 overlap are unchanged. Vec owners move between pools; wire/scalar buffers are not copied. One caller-owned ProofScope covers both stages. Canonical wire storage is converted exactly once and viewed through the original transparent-limb representation cast. Custom-pool callers, <=16 global workers, configured concurrency other than one, larger queries, GPU, equal-witness and ordinary five-part solving retain the current path. This is not a whole-proof worker cap or a private pool per arithmetic query. It avoids early global-pool entry for this proof; global workers may still spin after a preceding proof. It does not promise throughput gains.

Opt-in requires ZOPRO_CPU_PREFIX_POOL=1, otherwise the old early-entry path remains. One OnceLock caches success or failure per process. Eight explicit 2MiB stacks plus a declared 128KiB/worker guard/registry/bookkeeping allowance produce a 17MiB optional admission forecast. This allowance is an estimate, not a measured upper bound. The charge is held for process lifetime against the existing resource policy and forecasts, with constructor/admission failure falling back. No new universal memory ceiling or key table. Once constructed the pool stays resident under later memory pressure, a material limitation to examine before adoption. Pool creation/loading are included in whole-process RSS but priming excludes them from request latency by the existing protocol.

Audit: no current_thread_index/thread_local/UnsafeCell use found in solver or FFT source and their submodules; ProofScope/Reservation use process-global atomics and brief admission lock. Compile-time Send+Sync and a cross-pool canonical-storage ownership test accompany routing tests. Full native core plus raw/cubic and generated IFMA checks precede all proofs. Field math is unchanged; previous native field qualification is inherited, not rerun or newly claimed. Proof exports must pass independent Gnark verification, fixture public hashes, 164-byte proof length and prior-identity checks.
