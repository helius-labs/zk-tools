# Implementation details retained with the original declaration

The qualified xtask runner independently verifies each completed SDK process before starting the next. The design's wording "after each completed phase" was inaccurate. Verification and profile decoding occur between process captures and never overlap a request timer or profile. The deployed runner follows this existing behavior unchanged; no request or capture is rerun because of this documentation correction.

Artifact transport uses an owned private temporary S3 bucket and one-object900second PUT authorization, avoiding thousands of SSM chunk requests for task/profile records. Access keys/session credentials are never printed or persisted. Upload-command parameter files containing the URL are private, excluded from reports, and deleted after transport. The stored SSM command receipt excludes sensitive parameters. The owned object and bucket are removed after local size/SHA256 validation. The signing helper passes the AWS documented public signature vector, RFC4231 HMAC test and URI-encoding checks; a tiny owned upload/download check precedes transfer. This is transport work, not additional prover measurement.

The local correctness container runs as the host output-directory owner1000:1001 after an initial mount permission failure before any SDK call. The remote SSM-created output is root-owned and the measurement container runs as root with only PERFMON added, no network, a process limit, and unlimited memlock for perf buffers. No host sysctl, production service, networking rule or IAM policy is changed.
