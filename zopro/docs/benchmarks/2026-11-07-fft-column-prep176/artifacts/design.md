Current accepted column_kernel has80 butterfly multiplications per32-vector column. At gap1, a single root is used by16 butterflies, in both directions and both cached/uncached root layouts. Hypothesis: prepare an exact fixed-factor quotient in vector arithmetic on demand, use it only for those16 multiplications, then discard it. No per-key/domain table or retained cache. Proposed prepared object is10 SIMD words/640bytes plus bounded arithmetic temporaries; this is a payload model, not actual native stack/RSS. Prime-only reciprocal constant is6u64/48bytes per prime.

Distinction from closed work: fixed-leaf-fft/fixed-leaf-half retained prepared factors in Plan and regressed; half-root-fft used20-IFMA partial Montgomery preparation and a different80-IFMA product, applied at all reused stages. Neither is rerun or reinterpreted. The old full-width fixed-factor product uses exact c=floor(bR/p), but its constructor performs260 scalar binary-division iterations per factor. This stage replaces that constructor with a truncated reciprocal product and one correction, permitting an ephemeral final-stage-only candidate. Its eventual complete-column test must include canonical root decoding, new preparation,16fixed products,64unchanged products, all packing/output/checks and fixed scratch. No promise of a proof speedup or2× jump.

Let B=2^52,R=B^5 and canonical0<=b<p. Compile-time mu=floor(R²/p), six radix-B digits sinceR/B<p<R/2. Form only product terms of b*mu at degrees>=4 plus high halves at degree3. Let T be that retained integer and q0=floor(T/R). The omitted nonnegative part divided byR is below7/B+2/B²+1/B³<8/B. Reciprocal error is belowb/R<p/R<1/64 for BN254. Thus bR/p-(p/R+8/B)<T/R<=bR/p, with totalerror<1. Therefore floor(bR/p)-1<=q0<=floor(bR/p). D=bR-q0p is nonnegative and below2p<R. Compute D=(-q0p)modR using only the low five product digits. If D>=p, subtractp and incrementq0. The resulting quotient/remainder are EXACT. No floating point or approximate field output.

General model domain: five normalized operand digits, six reciprocal digits, R/B<p<R/2 and p/R+8/B<1. Exhaustive small-base p65537/B16 is a positive general-domain check, not a BN254 runtime claim. Full BN254 Fq/Fr checks include quotient-boundary inputs, prime/limb/power edges and deterministic full-width values.
