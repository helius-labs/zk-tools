# Identify the G2 windows that start first

The ordinary 1×2 release started a median of eleven out of twenty-two fills before its first fill returned. Test whether those fills cover eleven different windows, or both partitions of fewer windows. Record the window number, partition number and signed-window width at entry to the existing production closure on a private byte-identical binary. Check that every proof contains both partitions of all eleven windows at width twelve. Compare three independent 1×2 requests and the original 2×2.

Run two fresh paired blocks per input with plain and traced order reversed. Use 32 pinned hardware threads, three warmups and seventeen timed proofs per process. Report the number of distinct windows in the first eleven launches, the partition mix, partner launch lag, and the slowest finishing window. Require independent verification of each exported proof. Keep the proof data out of the captured arguments.
