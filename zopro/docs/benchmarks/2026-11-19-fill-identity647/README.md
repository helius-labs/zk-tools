# Window and partition identities during G2 launches

All 136 traced proofs contained both partitions of every signed window numbered 0–10 at width 12. Linux recorded the three integer arguments at entry to the ordinary binary's range closure. The matched return event came from the same thread. All 16 independent exports verified. Each input has two plain and two traced processes with 17 measured calls per process. Counts and durations are medians of process medians. The first eleven refers to launch order within each proof. Partner lag is the median within a proof of the absolute difference between start times for the two ranges of each window.

Partition one supplied the last finishing fill on 28/34 original 1×2 proofs and on 27/34 and 32/34 for the two additional witnesses. On 2×2 it finished last in 19/34. The first eleven launches on the original covered a median of 8.5 distinct windows across the two processes. Several windows therefore started both partitions while others waited. The asymmetric finish frequencies motivate a direct comparison of equal and unequal input lengths for the two partitions.
