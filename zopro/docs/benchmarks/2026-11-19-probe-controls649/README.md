# Probe overhead and executable backing on the ordinary and grouped paths

The same retained probe executable ran with trace events inactive and active. A third process used its byte-identical source executable. Six balanced blocks used every process order on each case. Each process primed three proofs, then timed seventeen. The two plain arms had identical environment, affinity and command arguments apart from executable and export paths. All 90 independent exports verified. Each traced process recorded the required 374 G2 fills and seventeen complete proofs with zero lost or throttled records.

On the same executable copy, dense G1 arithmetic probes cost 13.94% on 1×2. The phase-only probes cost 5.90% on 1×2 and 4.87% on 2×2. With probes inactive, the retained copies differed from their source by paired medians between −1.55% and +1.05% across these five panels. Use the plain runs for speed comparisons and the traces to identify timing and ordering.
