# Query dimension on satisfying witnesses

Test a different route to reducing multi-scalar multiplication work. For each frozen 1×2 and 2×2 solver image, compute the Fr rank of A and B query scalars in the existing semantic model. Then condition on the equations from rows with no assignment. Insert the difference between the semantic forms for A times B and C as a relation. The candidate dimension is rank(relations and query rows) minus rank(relations). It is a structural result within this abstraction. It cannot predict elapsed time or prove global minimality. Compare with proportional-only folding and report the complete counts. No runtime, key or proof change. No new SDK calls. A dense small-matrix oracle checks sparse elimination and quotient dimensions before real inputs.
